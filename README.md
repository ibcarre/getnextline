# get_next_line

A C function that reads a file line by line.

## Objective

Retrieve the next available line from a file descriptor, handling partial reads and preserving data between successive calls.

## Technical Highlights

- Reading from file descriptors.
- Buffer management.
- Dynamic memory allocation and deallocation.
- End-of-file and error handling, according to the project requirements.

## Technologies

- C
- File descriptors
- Memory management
